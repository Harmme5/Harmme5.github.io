# 我的博客

基于 Hugo + Stack 主题搭建的个人博客

## 功能特性

### 2026-06-12 添加的功能

#### 1. 阅读体验优化
- ✅ **字数统计和阅读时间** - 文章列表和详情页显示字数和预估阅读时间
- ✅ **页面顶部阅读进度条** - 滚动时显示当前阅读进度
- ✅ **目录进度条** - 文章目录增加进度指示和当前章节高亮
- ✅ **回到顶部按钮** - 滚动超过 300px 时显示，点击平滑返回顶部

#### 2. 代码块增强
- ✅ **代码复制按钮** - 悬停在代码块时显示复制按钮，点击复制代码

#### 3. 视觉效果
- ✅ **文章卡片悬停效果** - 列表页文章卡片悬停时上浮并显示阴影
- ✅ **滚动淡入动画** - 文章卡片滚动进入视口时淡入显示
- ✅ **文章封面图支持** - 支持在文章 front matter 中添加封面图
- ✅ **引用块美化** - 引用块增加左侧彩色边框、半透明背景和装饰性引号
- ✅ **首页打字机效果** - 副标题"知行合一"逐字显示，带光标闪烁动画

#### 4. 交互优化
- ✅ **图片灯箱功能** - 点击文章内图片可放大查看
- ✅ **整卡片可点击** - 列表页文章卡片整个区域可点击进入文章
- ✅ **点击粒子特效** - 页面点击时产生彩色粒子扩散效果

#### 5. 部署优化
- ✅ **自动化部署脚本** - `push.bat` 自动切换生产环境 URL 并部署

## 本地开发

```bash
# 启动本地服务器
hugo server

# 访问地址
http://localhost:1313/
```

## 部署

```bash
# 使用自动化脚本部署
push.bat
```

脚本会自动：
1. 将 baseURL 切换为生产环境
2. 重新构建站点
3. 还原 baseURL 为本地调试
4. 提交并推送到 GitHub

## 技术栈

- **静态站点生成器**: Hugo
- **主题**: Stack (自定义修改版)
- **托管**: GitHub Pages
- **域名**: https://Harmme5.github.io/

## 项目结构

```
my-blog/
├── content/          # Markdown 文章
├── layouts/          # 自定义模板
│   ├── index.html    # 首页模板
│   └── partials/     # 组件模板
├── static/           # 静态资源
│   └── img/covers/   # 文章封面图
├── themes/stack1/    # Stack 主题
├── public/           # 生成的静态站点
├── hugo.toml         # 站点配置
└── push.bat          # 部署脚本
```
